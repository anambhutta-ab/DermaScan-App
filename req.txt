# DermaScan App - Requirements and Dependencies
# ===========================================

## Project Overview
DermaScan is a Flutter-based mobile application for dermatology/skin disease scanning and detection. The app uses AI/ML models to classify skin conditions from images and provides users with disease information, scan history, and AI-powered chat assistance.

## Flutter SDK Requirements
- Flutter SDK: ^3.8.1 or later
- Dart SDK: Compatible with Flutter 3.8.1

## ML Model Requirements
# ======================
# The app uses TensorFlow Lite (.tflite) models for skin disease detection:
# - acne_resnet50_final_bayesian_98%.tflite
# - ak_resnet50_final_97_bayesian.tflite (Actinic Keratosis)
# - eczema_efficientnetb2_final.tflite
# - lupus_efficientnetb3_final.tflite
# - mel_effb3_final_92_bayesian.tflite (Melanoma)
# - psoriasis_resnet50_final.tflite
# - ringworm_resnet50_final.tflite
# - warts_resnet50_final_91_bayesian.tflite
